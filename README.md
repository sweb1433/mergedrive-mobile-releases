# MergeDrive mobile releases

Download published Android APKs from [Releases](https://github.com/sweb1433/mergedrive-mobile-releases/releases).

MergeDrive helps you manage files across your connected storage accounts.

Website: [mergedrive.online](https://mergedrive.online)

## Install or update on Android

1. Open the latest stable release and download its `.apk` asset.
2. Open the downloaded APK and allow installation from your browser or file manager if Android asks.
3. Confirm **Install** or **Update**. Keep the existing app installed to preserve its data.

## Publish an APK

- Create a release with the app version as its tag, for example `v1.0.1`, targeting `main`.
- Attach the signed `MergeDrive-1.0.1-android.apk` and, optionally, its `.sha256` checksum file.
- Use a higher Android version code and the original signing key for future app versions.
- Publish as a stable release and mark it as latest when ready for users.

This repository holds public installer releases. Application source and signing credentials are maintained separately.
